# Test — v0.3 groups (2026-11-13)

Same setup as the [v0.1 end-to-end test](2026-11-10-e2e-v0.1.md). To avoid involving anyone
else, the test group was created with the instance's own number only, and the number left it
at the end.

| Step | Result |
|---|---|
| `GET /groups` | OK — 200, every joined group listed (member lists left out) |
| `POST /groups` with only `name` | OK — 201, group with 1 member (this number, admin) |
| `PATCH /groups/{jid}` description + `announce: true` | OK — 200; `GET` shows both |
| `GET /groups/{jid}/invite` | OK — `https://chat.whatsapp.com/…` |
| `POST /groups/{jid}/invite/reset` | OK — a different link |
| `participants` with an unknown action | OK — 400, nothing sent |
| `GET` a group that does not exist | OK — 404 `group not found, or this number is not in it` |
| `POST /groups/{jid}/leave` | OK — 200 |
| `group.update` events | OK — joined (with name), description, announce, invite reset, leave; all signed |
| Sending counters | OK — create, settings, reset and leave counted (4) |

Not covered yet: adding, removing, promoting and demoting real people (needs a second
consenting number), and joining by link.
