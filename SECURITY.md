# Security Policy

**English** · [Português](#política-de-segurança)

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report it privately through
[GitHub Security Advisories](https://github.com/firezaprepo/firezap-api/security/advisories/new),
with the steps to reproduce and the version affected. We will acknowledge the report and keep you
updated until a fix is released.

## Supported versions

The project is in early development. Only the latest version on `main` receives security fixes.

# Política de segurança

## Como reportar uma vulnerabilidade

Por favor, **não abra uma issue pública** para problemas de segurança.

Reporte em particular pelo
[GitHub Security Advisories](https://github.com/firezaprepo/firezap-api/security/advisories/new),
com os passos para reproduzir e a versão afetada. Confirmaremos o recebimento e manteremos você
informado até a correção ser publicada.

## Versões com suporte

O projeto está no começo do desenvolvimento. Só a versão mais recente na `main` recebe correções
de segurança.
